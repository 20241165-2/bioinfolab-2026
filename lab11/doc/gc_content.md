# gc_content.py 사용법

FASTQ 파일의 각 read 에 대해 GC 비율과 평균 품질을 함께 계산한다.
GC 비율이 가장 높은 read 10개와 가장 낮은 read 10개를 골라
그 read 들의 평균 품질을 전체 평균과 비교한다.

## 실행

```
$ cd lab11/src
$ python3 gc_content.py <FASTQ 파일>
```

| 인자 | 설명 |
|------|------|
| `<FASTQ 파일>` | 읽을 FASTQ 파일 경로 (Phred+33) |

인자 개수가 틀리면 사용법을 출력하고 종료한다.

결과를 파일로 저장하려면 `>` 를 쓴다.

```
$ python3 gc_content.py ../data/SRR1553607_1.fastq > result.txt
```

## 출력 예

```
$ python3 gc_content.py ../data/SRR1553607_1.fastq
read 개수: 203445

[GC 비율이 가장 높은 read 10개]
read	GC(%)	평균품질
SRR1553607.53820	98.02	11.10
...
[GC 비율이 가장 낮은 read 10개]
read	GC(%)	평균품질
SRR1553607.166164	12.87	39.66
...
[평균 품질 비교]
그룹	평균품질	전체와의 차이
전체	33.45	0.00
GC 높음	17.31	-16.14
GC 낮음	38.33	+4.88
```

| 항목 | 내용 |
|------|------|
| `GC(%)` | (G+C) ÷ (A+T+G+C) × 100, N 은 뺀다 |
| `평균품질` | read 품질 점수의 평균 |
| `전체` | 모든 read 평균품질의 평균 |
| `전체와의 차이` | 그룹 평균품질 - 전체 평균품질 |
