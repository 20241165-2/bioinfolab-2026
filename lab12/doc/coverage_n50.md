# 커버리지와 N50 의 관계

## 1. 실험 전 예상

- 커버리지 = 전체 염기 수 / 유전체 크기. 원본은 3,744,000 bp / 약 180 kbp ≈ **약 20배**.
- 데이터를 절반으로 줄이면 커버리지는 **약 10배**가 된다.
- 예상: **커버리지를 줄이면 N50 이 작아지고 contig 개수는 늘어난다.**
  - 리드는 유전체에서 무작위로 뽑히므로, 평균 커버리지가 낮아지면 우연히 리드가 거의 없는 구간(0~2배)이 생긴다.
    어셈블러는 그런 구간을 이을 수 없어서 contig 가 끊긴다.
  - SKESA 같은 어셈블러는 너무 적게 나온 k-mer 를 오류로 보고 버리므로, 커버리지가 낮은 구간은 진짜 서열도 버려질 수 있다.
  - 그래서 전체 조립 길이도 조금 줄어들 수 있다.
- 다만 20배 → 10배는 아직 "아주 낮은" 수준은 아니므로, 큰 붕괴보다는 N50 이 눈에 띄게 줄어드는 정도일 것이라고 예상한다.

## 2. 실행 방법

paired-end 데이터이므로 R1 과 R2 에 **같은 seed(`-s 11`)** 를 주어야 같은 짝이 뽑힌다.

```
$ seqkit sample -p 0.5 -s 11 data/R1.fastq -o data/R1.half.fastq
$ seqkit sample -p 0.5 -s 11 data/R2.fastq -o data/R2.half.fastq
$ python3 ../lab11/src/check_paired.py data/R1.half.fastq data/R2.half.fastq   # 짝이 안 맞는 read 0개
$ micromamba run -n assembly skesa --reads data/R1.half.fastq,data/R2.half.fastq \
        --cores 4 --contigs_out doc/skesa_half_out/contigs.fa
$ cd src
$ python3 n50.py ../doc/skesa_half_out/contigs.fa ../doc/contig_lengths_half.txt
```

- 어셈블러는 원본 조립(`doc/trim_compare.md`)과 같은 SKESA 를 썼다. (SPAdes 는 이 Codespace 에서 실행되지 않음)
- 유전체 크기는 원본 조립 전체 길이 178,467 bp 로 잡았다.

## 3. 결과

| 조건 | read 쌍 | 염기 수 | 커버리지 | contig 개수 | 전체 길이 (bp) | 가장 긴 contig | N50 |
|------|--------:|--------:|---------:|------------:|---------------:|---------------:|----:|

## 4. 예상과 비교

**방향은 예상대로였지만, 변화 폭은 예상보다 훨씬 컸다.**

- 예상대로: N50 은 줄고(34,941 → 5,909), contig 는 늘고(9 → 44), 전체 길이는 조금 줄었다(178,467 → 172,155, 약 6.3 kbp 손실).
- 예상과 다른 점: 커버리지는 절반이 되었을 뿐인데 N50 은 **약 1/6** 로 줄었다. "눈에 띄게 줄어드는 정도"가 아니라 조립이 크게 쪼개졌다.
  1 kbp 미만의 짧은 contig 도 14개 생겼다.

### 왜 절반보다 훨씬 많이 나빠졌을까

- 커버리지와 N50 은 정비례가 아니다. 평균 커버리지가 낮아지면 "리드가 거의 없는 구간"의 개수는 훨씬 빠르게 늘어난다.
  리드가 무작위로 놓인다고 보면(포아송 분포), 평균 10배일 때 어떤 위치를 2번 이하로 읽을 확률은 약 0.3% 이고, 평균 20배일 때는 거의 0 에 가깝다.
  180 kbp 유전체에서 0.3% 는 수백 개의 위치이므로, 이 중 일부가 끊김을 만든다.
- 어셈블러는 리드 길이(150 bp)보다 짧은 k-mer 로 그래프를 만드므로, 실제로 중요한 것은 **k-mer 커버리지**이다.
  k-mer 커버리지는 리드 커버리지 × (리드 길이 − k + 1) / 리드 길이 로, 리드 커버리지보다 더 낮다.
  SKESA 는 적게 나온 k-mer 를 오류로 보고 버리므로, 10배 정도에서는 진짜 서열의 k-mer 도 버려지는 곳이 생긴다.
- 즉 20배 근처는 "충분한" 쪽, 10배 근처는 "부족해지기 시작하는" 쪽이어서 그 사이에서 N50 이 급격히 떨어진 것으로 보인다.

### 결론

커버리지가 낮아지면 N50 이 작아진다. 그리고 그 관계는 직선이 아니어서, 어느 수준 아래로 내려가면 N50 이 급격히 무너진다.
